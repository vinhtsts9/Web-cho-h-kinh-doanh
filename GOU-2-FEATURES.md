# Gói 2: Ecommerce Platform - Danh Sách Tính Năng & Giá

> **Gói 2** dành cho các kinh doanh bán lẻ: Shop quần áo, phụ kiện, đồ chơi, mỹ phẩm, thực phẩm, v.v.
> 
> **Mục đích:** Xây dựng nền tảng bán hàng trực tuyến đầy đủ với quản lý hàng tồn kho, đơn hàng, thanh toán.

## ✨ Tính Năng Gói 2

- [ ] Danh sách sản phẩm (grid/list view)

- [ ] Lọc theo danh mục, giá, rating

- [ ] Đăng ký / Đăng nhập

- [ ] Order history
- [ ] Wishlist / Save for later
- [ ] Password reset
- [ ] Email verification

### **4. Admin Dashboard**
- [ ] Login Admin
- [ ] Dashboard overview (sales, orders, revenue)
- [ ] Quản lý sản phẩm:
  - [ ] Thêm/sửa/xóa sản phẩm
  - [ ] Upload ảnh product
  - [ ] Cập nhật giá & tồn kho
  - [ ] Manage categories
- [ ] Quản lý đơn hàng:
  - [ ] Danh sách đơn hàng
  - [ ] Cập nhật status (pending/processing/shipped/delivered)
  - [ ] In order / Xuất file CSV
- [ ] Quản lý khách hàng:
  - [ ] Danh sách khách
  - [ ] Thống kê mua hàng
- [ ] Quản lý coupon/promotion
- [ ] Analytics & Report (doanh thu theo tháng, sản phẩm bán chạy)

### **5. Notification & Communication**

### **6. SEO & Performance**
